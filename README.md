# MultiChat + озвучка (Twitch, YouTube, TikTok, Kick)

Поточна версія: **1.1.13**. Номер версії задається в `package.json`; застосунок автоматично показує його внизу лівої панелі. Для майбутнього релізу онови це поле за SemVer — інтерфейс підхопить його автоматично.

Широкий логотип у шапці інтерфейсу зберігається в `public/assets/multichat-wordmark.png`. Іконка вікна та Windows-збірки — `assets/icon.ico`.

MultiChat об'єднує чати Twitch, YouTube, TikTok і Kick в одному вікні, показує події та лічильники глядачів, озвучує повідомлення українською і надає окрему панель чату для OBS.

## Можливості програми

- **Чотири платформи в одному чаті:** Twitch, YouTube, TikTok та Kick; нікнейми/посилання на канали, автоматичне підключення до активних ефірів і кольорові мітки платформи.
- **Авторизація і події платформ:** OAuth-вхід для Twitch, YouTube та Kick; підтримка нових підписників, фолів, подарунків, рейдів, бітів, нагород та інших доступних для акаунта подій. Для TikTok доступний ключ Euler Stream.
- **Озвучення повідомлень українською:** онлайн-голоси й офлайн-голоси Piper, вибір голосу, швидкість, висота та гучність; фільтри для команд, згадувань, символів, посилань, платформ, довжини повідомлення і заборонених слів; черга мовлення та виключення глядачів.
- **Події чату:** незалежне відображення та озвучення подій, налаштування типів подій (підписки, фоли, подарунки, рейди тощо).
- **Керування чатом:** лічильники глядачів та статус з'єднання, черга повідомлень, пропуск і очищення чату, копіювання тексту/ніка/посилань, вимкнення озвучення окремих глядачів.
- **OBS:** окрема браузерна панель чату з повідомленнями, керуванням і лічильниками CPU/RAM; підказка в налаштуваннях пояснює, як додати панель як Browser Dock.
- **Стабільність і налаштування Windows:** теми інтерфейсу, апаратне прискорення, режим запуску, пріоритет процесу, діагностика Kick, індикатори CPU/RAM і звукове сповіщення про втрату інтернету.
- **Авторизація й облікові дані:** API-ключі зберігаються окремо від підключень; облікові дані використовуються локально на комп'ютері.

Докладні параметри кожної функції, вимоги та інструкції наведені нижче в цьому README.

## Приватність налаштувань

`config.json`, `accounts.json`, `settings.json`, папка `voices`, `.env` та файли журналів — це локальні дані користувача. Вони виключені з Git через `.gitignore`, з Windows-збірки — правилами Electron Packager, а workflow додатково зупиняє реліз, якщо знайде їх у пакеті. `config.example.json` містить лише порожні поля для прикладу, без ключів чи токенів. Програма створює особисті файли лише під час запуску на комп'ютері користувача.

## Релізи та версії

Готові збірки Windows публікуються у вкладці **Releases** як `MultiChat-<версія>-windows-x64.zip` (архів містить `MultiChat.exe` і потрібні файли). Повний опис можливостей програми — у розділі «Можливості програми» та інструкціях нижче; історія змін — у [`CHANGELOG.md`](CHANGELOG.md).

Для кожного релізу: онови версію в `package.json`, додай повний розділ `## [версія]` у `CHANGELOG.md`, потім створи й надішли Git-тег `v<версія>`. GitHub Actions перевірить відповідність тегу версії та наявність нотаток, збере Windows `.exe`, перевірить відсутність особистих файлів, створить GitHub Release і прикріпить ZIP. Ручний запуск workflow створює збірку як артефакт Actions без публікації релізу.

## Швидкий старт

### Варіант А - програма для Windows (MultiChat.exe)
1. Один раз збери її: двічі клікни **`build-exe.bat`** (потрібні Node.js 18+ та інтернет, збірка 2-5 хв).
   Готова програма: папка `dist\MultiChat-win32-x64\`, запускай `MultiChat.exe` в ній (папку можна скопіювати куди завгодно).
   Не хочеш ставити Node.js? Завантаж проєкт на GitHub: вкладка Actions, Build MultiChat, Run workflow, завантаж артефакт `MultiChat-win`.
2. `MultiChat.exe` відкриває власне вікно. Закриєш вікно, і програма вимкнеться. Поки вона працює, чат доступний і для OBS на http://localhost:3000.
3. Поруч з `MultiChat.exe` створюються `accounts.json` (твої ніки), `config.json` (ключі) і папка `voices` (офлайн-голоси).
4. Вхід через Google, Twitch чи Kick відкривається в твоєму звичайному браузері (Google не пускає вхід у вікнах програм); після входу повертайся у вікно MultiChat.
5. Windows SmartScreen може попередити про невідомого видавця (файл не підписаний): «Додаткові відомості», потім «Все одно виконати».

### Варіант Б - через Node.js
`npm install`, потім `npm start` (або двічі клікнути `start.bat`), далі http://localhost:3000

## Як влаштовані налаштування
Ліва панель поділена на гілки за темами. У кожній гілці налаштування згруповані в підрозділи-кнопки, стан розгортання запам'ятовується; угорі є кнопки «Розгорнути все» і «Згорнути все»:
- **Підключення:** підрозділ «Акаунти»; у заголовку видно, скільки платформ підключено;
- **API-ключі:** окрема головна гілка з ключами для кнопок «Увійти»;
- **Озвучка:** перемикач «Озвучувати чат» і підрозділи «Голос і звук» (голос, офлайн-голоси, швидкість, висота, гучність, тест),
  «Що озвучувати» (нікнейм, команди, згадування, символи, посилання, платформи) і «Обмеження і винятки» (довжина, черга, префікс, заборонені слова, глядачі-винятки);
- **Події в чаті:** перемикачі «Показувати події в чаті» й «Озвучувати події», а також підрозділ «Налаштування типів подій»;
- **OBS - чат у панелі:** підрозділ «Параметри панелі» з підказкою, як додати панель у OBS;
- **Програма:** підрозділи «Продуктивність», «Режим запуску», «Звук втрати інтернет-з'єднання», «API-ключі» та «Для розробників» із діагностикою Kick.

## Підключення акаунтів
Біля кожного сервісу є поле для ніка і кнопка **«Увійти»** (додатковий спосіб авторизації).

| Платформа | Спосіб 1 (без ключів) | Спосіб 2: кнопка «Увійти» |
|---|---|---|
| Twitch | нік каналу (наприклад `imakcoc`) | OAuth: додає фоли, нагороди за бали, Hype Train |
| YouTube | `@handle` або посилання на стрім | вхід через Google: автопідключення за твоїм каналом, нові підписники |
| Kick | нік каналу | OAuth: підтягує нік каналу |
| TikTok | `@нік` акаунта | недоступно: TikTok не надає входу для читання чату (можна додати безкоштовний ключ Euler Stream, див. нижче) |

Щоб кнопки «Увійти» працювали, один раз додай ключі в блоці **«Ключі для кнопок Увійти»** (Client ID і Secret).
Redirect URI показується прямо там, він має збігатися з тим, що ти вкажеш на сайті сервісу:
- Twitch: https://dev.twitch.tv/console (Client Type: Confidential)
- Google: https://console.cloud.google.com, увімкни YouTube Data API v3, створи OAuth client (Web application), у режимі Testing додай свій акаунт у Test users, а для стабільного доступу натисни Publish app
- Kick: https://kick.com/settings/developer (потрібна 2FA)

**TikTok і помилка «Failed to sign request»:** бібліотека підписує запити через зовнішній сервер підписів. Старі версії бібліотеки перестали працювати,
тому оновлено до актуальної, а перевірка ефіру робиться без підпису (поки стріму немає, запитів до сервера підписів немає). Якщо помилка з'являється під час стріму
(ліміт запитів), отримай безкоштовний ключ на https://www.eulerstream.com і встав його в блоці «Ключі для кнопок Увійти», рядок TikTok.

Ключі зберігаються в `config.json` поруч із програмою. Після підключення застосунок сам з'єднується зі стрімами, щойно ти в ефірі, і так само при кожному запуску.

## Статус і лічильники
- Угорі значки платформ з логотипами й текстом **Онлайн** (стрім у ефірі) або **Офлайн** (стріму немає). Крапка знизу показує підключення
  до чату: зелена - підключено, жовта - підключення, синя - очікування стріму, червона - помилка, сіра - не підключено.
  Червона крапка зверху - LIVE. Клік по значку ховає або показує повідомлення платформи.
  Як визначається ефір: Twitch - публічний запит раз на 30 с; YouTube - після входу через API, інакше зі сторінки каналу; TikTok - перевірка
  перед підключенням; Kick - публічний API (якщо Cloudflare його блокує, значок оновлюється лише за подіями чату).
- Внизу чату лічильники глядачів: іконка платформи і кількість (0 показується як 0), після `|` загальна кількість.
  Джерела: TikTok (подія кімнати), Twitch (публічний запит, раз на 30 с), YouTube (API після входу, інакше сторінка відео),
  Kick (публічний API, раз на 45 с). Частина джерел неофіційна й може змінитися.
- Блоки-підказки та інструкція OBS згортаються; стан запам'ятовується.

## Події (подарунки, підписки, фоли...)
Показ і озвучку кожного типу окремо вмикає таблиця в блоці «Події», є і загальні перемикачі «Показувати події в чаті» та «Озвучувати події».
| Платформа | Події |
|---|---|
| Twitch | підписки, подарунки, рейди, біти; після входу ще фоли, нагороди за бали, Hype Train |
| YouTube | нові учасники каналу; після входу нові підписники (раз на хвилину, поки йде стрім; приховані підписки не видно) |
| TikTok | подарунки, фоли, підписки, репости («поділився стрімом»); лайки й заходи глядачів не показуються (це спам) |
| Kick | підписки, подаровані підписки, хости/рейди, нагороди за бали, фоли, Kicks (неофіційний канал, поля можуть змінюватись) |

## Озвучка (лише українська)
- **Онлайн:** Polina (жін., нейронний, Microsoft Edge TTS) і Google Translate (жін.); також Ostap (чол.). Через сервер, потрібен інтернет,
  доступ неофіційний; текст чату йде на сервери Microsoft або Google.
- **Офлайн (Piper):** Tetiana (жін., висока якість, ~115 МБ) і Lada (жін., проста, швидка, ~21 МБ).
  Блок «Офлайн-голоси (завантаження)», кнопка «Завантажити»: рушій і голос завантажуються в папку `voices` поруч із програмою
  (якщо в шляху є кирилиця, використовується `C:\ProgramData\MultiChat\voices`, бо Piper не відкриває такі шляхи).
  Інтернет потрібен лише для завантаження. Автовстановлення: Windows і Linux x64.
- **Не працює офлайн-голос?** Натисни «Перевірити голос» у блоці офлайн-голосів: покаже, де проблема (немає рушія, немає файлів, помилка запуску).
  Причину також видно в чаті, коли голос не спрацював.
- Системні голоси ОС: у Windows додай українську в Налаштування, Час і мова, Мовлення.
- **Виняток:** поле «Не озвучувати цих глядачів» (нікнейми через кому або з нового рядка). Швидко додати: наведи курсор на повідомлення й натисни 🔇.
  Виняток діє і для повідомлень, і для подій.
- Повзунок «Висота» діє лише на системні голоси; швидкість працює для всіх.
- **Що не озвучується:** команди (повідомлення, що починаються з `!`, також після згадування), згадування `@нік` (решта тексту читається повністю:
  «Привіт, @User123, як справи?» звучить як «Привіт, як справи?»), посилання, емодзі та зайві символи (`@ # * ~ < >` тощо), однакові повідомлення,
  що повторилися за кілька секунд. У нікнеймі `_` і `.` читаються як пауза. Усе вимикається галочками в блоці «Озвучка».
- **Озвучує лише одне вікно.** Якщо відкрито кілька (програма, вкладка браузера, панель OBS із `&tts=1`), говорить одне, інші мовчать, а вгорі пишеться,
  де зараз озвучка. Пріоритет: вікно, у якому ти востаннє клікав або тиснув клавішу; інакше вікно програми. Це прибирає ситуацію, коли одне
  повідомлення читають два голоси. Якщо онлайн-голос не спрацював, читає системний український голос, а за його відсутності повідомлення пропускається
  (англійський голос кирилицю не читає).

## Чат як панель в OBS
У застосунку є блок **«OBS - чат у панелі»** з готовим посиланням і кнопкою «Копіювати» (`http://localhost:3000/?dock=1`).
Підказка «Як додати в OBS» розташована в «Параметрах панелі» й згортається. Застосунок має бути запущений. У панелі озвучка вимкнена (читає застосунок);
галочка в блоці додає `&tts=1`.

## Кнопки керування чатом
Унизу чату (також у панелі OBS) три кнопки: **Пропустити** (пропускає повідомлення, що озвучується зараз), **Очистити чергу** (прибирає все, що чекає озвучення)
і **Очистити чат** (очищає стрічку). Кнопки з панелі OBS керують вікном, яке озвучує. Смуги прокручування приховані і в панелі OBS, і в самому застосунку (чат, ліва панель), а гортати можна колесом миші, тачпадом або клавішами.

## Апаратне прискорення
Блок «Програма»: перемикач **Увімкнено / Вимкнено**. Працює в програмі `MultiChat.exe` (у браузері налаштовується в самому браузері).
Зміна потребує перезапуску: з'являється кнопка «Перезапустити програму». Налаштування зберігається в `settings.json` поруч із програмою.
Якщо інтерфейс чи звук працюють нестабільно, спробуй вимкнути прискорення.

## Чат Kick
**Чому раніше працювало, а тепер ні.** Адреса й ключ Pusher у застосунку не змінювались від перших версій. Змінив усе Kick: він покинув хмарний Pusher,
тому старий публічний ключ тепер відповідає `App key ... not in this cluster (код 4001)` на кожному кластері, а новий шлюз `websockets.kick.com` вимагає
одноразового токена, який видається лише справжньому браузеру (Cloudflare).

**Як працює тепер (у програмі `MultiChat.exe`).** Застосунок відкриває сторінку чату Kick (`kick.com/popout/<нік>/chat`) у прихованому вікні вбудованого
Chromium і читає кадри її WebSocket через протокол DevTools. Сторінка сама отримує токен, підключається й підписується, а застосунок бере ті самі події
(повідомлення, підписки, подарунки, фоли, нагороди). Дані каналу (стрім в ефірі, глядачі) запитуються через ту саму сесію Chromium.
- Якщо Cloudflare попросить перевірку, у картці Kick з'явиться кнопка **«Показати вікно Kick»**: пройди перевірку, і вікно сховається саме.
- Збої не створюють нескінченного циклу: паузи між спробами ростуть (3, 6, 12... до 60 с); якщо чат довго мовчить (5 хв без жодного кадру), вікно відкривається заново.
- У режимі `npm start` у звичайному браузері читати чат Kick не вдається (немає вбудованого браузера): застосунок один раз пояснює це й перевіряє раз на 10 хв,
  замість того щоб без кінця перепідключатися. Для Kick запускай `MultiChat.exe`.

## TikTok: текст повідомлень і глядачі
- Текст береться з поля `comment`, а якщо TikTok змінить формат, шукаються схожі поля (`content`, `text`). Повідомлення без тексту в чаті не показуються,
  натомість один раз з'являється пояснення. Для діагностики: `set DEBUG_EVENTS=1 && npm start`.
- Лічильник глядачів оновлюється подіями кімнати. Якщо вони не приходять довше 45 с, лічильник береться з інформації про кімнату (раз на 30 с).

## Ключі в налаштуваннях
- Усі поля ключів за замовчуванням приховані (крапки). Кнопка-око біля поля показує або ховає лише цей ключ; значення не змінюється, стан видно по кнопці
  (перекреслене око приховано, підсвічене показано).
- Введені ключі лишаються в полях після збереження, входу й перезапуску (зберігаються в браузері або програмі), їх можна редагувати.
- **Очистити API-ключі:** після підтвердження видаляє ключі з полів, з пам'яті браузера і з `config.json`; токени доступу Twitch і YouTube теж прибираються
  (нік і канал лишаються, чат працює далі без входу), а підключення TikTok перезапускається без ключа Euler Stream. Автоматично ключі не відновлюються.

## Налагодження
`set DEBUG_EVENTS=1 && npm start` - в консолі видно сирі події YouTube/Kick.
Якщо порт 3000 зайнятий, закрий іншу копію застосунку.

## Додаткові налаштування (група «Програма»: Продуктивність, Режим запуску, Звук втрати інтернет-з'єднання)

**Пріоритет процесу** (Програма -> Продуктивність). Шість рівнів: Низький (Idle), Нижче звичайного, Звичайний (за замовчуванням), Вище звичайного, Високий, Реального часу. Для стримінгу достатньо «Звичайний» або «Вище звичайного». Змінюється пріоритет лише самої програми (вікно, вбудований браузер Kick), інші процеси Windows не чіпаються. Застосовується одразу, зберігається в `settings.json`. «Реального часу» перед увімкненням просить підтвердження: цей рівень може підвісити Windows і OBS, а без прав адміністратора Windows сама знижує його до «Високого» (програма покаже про це повідомлення).

**Запуск від імені адміністратора** (Програма -> Режим запуску). За замовчуванням звичайний запуск. Після зміни режиму потрібен перезапуск (кнопка в налаштуваннях). Якщо обрано режим адміністратора, Windows покаже вікно UAC. Якщо відмовити, програма запуститься у звичайному режимі й покаже пояснення; повторних запитів і циклічних перезапусків немає. Повернення зі режиму адміністратора до звичайного працює через перезапуск з кнопки в налаштуваннях. Доступно лише в `MultiChat.exe` на Windows.

**Звук втрати інтернету.** 15 вбудованих сигналів у 5 категоріях (тихі та короткі, стандартні, гучні, довгі, комбіновані), кнопка «Прослухати», гучність у відсотках (повзунок 0-100% і числове поле, крок 1%, окрема від гучності голосу бота; 0% - без звуку), перемикач «Увімкнути звук сповіщення», повтор кожні 3, 5, 10 або 30 с, поки інтернету немає (кнопка «Добре» у вікні сповіщення зупиняє повтор). Сигнал лунає одразу після втрати, не лунає під час відновлення і лунає знову, якщо інтернет зник повторно. Якщо звук вимкнено або гучність 0%, лишаються вікно і банер без звуку. Звук лунає лише у вікні програми, не в панелі OBS, і не перериває озвучення чату. Вибір зберігається після перезапуску.

## Гучність голосу бота (блок «Озвучення»)

Параметр «Гучність голосу бота (%)»: повзунок від 0% до 100% і числове поле, які змінюються разом (крок 1%, значення поза межами обмежуються до 0 або 100, дробові округлюються). 0% повністю вимикає звук бота (повідомлення не завантажуються й не звучать), 100% - максимальна гучність у застосунку. Зміна діє одразу, навіть на голос, що зараз звучить (крім системного голосу: його реплика дограє з попередньою гучністю, нова гучність діє з наступної), зберігається після перезапуску і застосовується до всіх голосів (Edge, Google, Piper, системні). Регулюється лише гучність самого застосунку: гучність інших програм Windows, системні звуки і звук сповіщення про втрату інтернету не змінюються. Старі збережені значення (частка 0..1) автоматично переносяться у відсотки.

## Мут глядача в панелі OBS

Іконка 🔇 біля повідомлення (з'являється при наведенні миші) тепер є і в чаті-панелі OBS, не лише у вікні програми. Клік у панелі OBS додає глядача до списку «не озвучувати» у вікні програми (воно зберігає список і озвучує чат), а клік у програмі передається в панель. Нік не дублюється, регістр не важливий. Прибрати глядача зі списку можна в блоці «Озвучка» у вікні програми. Якщо вікно програми не відкрите, клік у панелі OBS нікому не передається.

## Закриття програми

Закриття головного вікна повністю завершує програму: знищується і прихований браузер Kick, зупиняються процеси озвучення Piper, нові вікна й повторні підключення під час виходу не створюються. Якщо щось зависне, через 2,5 с програма завершується примусово.

## Показники навантаження (нижня панель чату)

У нижній панелі вікна програми, праворуч від лічильників глядачів (у самому правому куті), показуються CPU і RAM, наприклад «CPU 18% | RAM 62% (9,9 ГБ)». За замовчуванням це навантаження лише самого застосунку (усі його процеси: вікно, відео/GPU, прихований браузер Kick), у відсотках від усього процесора та пам'яті комп'ютера; обсяг пам'яті в дужках можна вимкнути, а також обрати один із двох форматів: «Використано» - «RAM 62% (9,9 ГБ)» «Використано і залишок» - «RAM 62% (9,9 ГБ, вільно 6,1 ГБ)» (залишок - вільна оперативна пам'ять усього комп'ютера) або «Використано і весь обсяг» - «RAM 62% (9,9/16 ГБ)» (весь обсяг - уся пам'ять, встановлена на ПК). До 1 ГБ використане показується в МБ, наприклад «1,5% (240 МБ)» або «1,5% (240 МБ/16 ГБ)». У налаштуваннях (Програма, Продуктивність) можна перемкнути на «Вся система» або повністю вимкнути показники.

Дані беруться з метрик процесів Electron/Chromium та модуля `os` (системні виклики Windows), без PowerShell/WMI і без прав адміністратора. Оновлення раз на 1,5 с. Збір працює лише поки є вікно, яке показує показники, і воно видиме; якщо показники вимкнено, вікно згорнуто або закрито, сервер нічого не вимірює. Одне вимірювання займає соті частки мілісекунди. Якщо даних немає (ще не надійшли, перестали надходити понад 6 с), показується «—». Кольори беруться зі змінних теми, тому читаються і в темній, і в світлій темі (контраст понад 4,5:1).

У вужчому вікні показники скорочуються ступінчасто, щоб лічильники глядачів не зсувались і панель не ставала вищою: спершу ховаються підписи CPU/RAM, потім залишок (а «9,9/16 ГБ» скорочується до «9,9 ГБ»), потім обсяг у дужках (лишаються відсотки), а у вікні вужчому за 825 пікс. показники ховаються зовсім. Пороги підібрано вимірюванням для найдовших значень.

## Права кнопка миші (копіювати, вставити)

У вікні програми працює контекстне меню (файл `contextmenu.js`):
- у полях введення (нік каналу, ключі API, списки): Скасувати, Повторити, Вирізати, Копіювати, Вставити, Виділити все;
- у чаті: на виділеному тексті «Копіювати»; на повідомленні без виділення «Копіювати текст повідомлення» і «Копіювати нік»; «Виділити весь чат» (потім Ctrl+C або права кнопка);
- на посиланні: «Відкрити посилання в браузері» і «Копіювати адресу посилання» (лише http/https);
- на іконці 🔇 меню не з'являється, щоб випадково не заглушити глядача.
Гарячі клавіші Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+A, Ctrl+Z працюють як зазвичай.

### Показники в панелі OBS

Ті самі показники CPU/RAM показуються й у чаті-панелі OBS, в її нижній частині праворуч. Вимкнути їх можна в налаштуваннях програми, у групі «OBS - чат у панелі», вимикачем «Показувати навантаження (CPU, RAM) у нижній панелі». Вимикач, а також режим («Лише застосунок» / «Вся система») і формат обсягу в дужках беруться з налаштувань програми й діють у панелі одразу, посилання в OBS копіювати заново не потрібно (панель OBS - окремий браузер зі своїм сховищем, тому програма передає налаштування панелі через сервер). Показ у програмі й показ в OBS вмикаються незалежно; коли вимкнено обидва, збір даних зупиняється повністю. Якщо панель OBS сховано (вкладка чи док згорнуті), вона теж не просить дані.

У вузькій панелі (типово 300-400 пікселів) показники не вміщаються в рядок із лічильниками й переходять на власний рядок праворуч під ними. Якщо й там тісно, довгі формати скорочуються ступінчасто (підписи CPU/RAM, залишок, «9,9/16 ГБ» до «9,9 ГБ», обсяг у дужках), аж до самих відсотків; пороги підібрано вимірюванням для найдовших значень. Якщо вікно програми закрите, панель працює з типовими налаштуваннями (лише застосунок, обсяг у дужках «Використано»).

## Інструкція з отримання API-ключів у програмі

У розділі «🔑 API-ключі» (його видно, коли ввімкнено перемикач у «⚙️ Програма»), у підблоці «Ключі для кнопок «Увійти»», є кнопка «📘 Покрокова інструкція: як отримати ключі». Вона відкриває вікно з вкладками: «Загальне», «YouTube», «Twitch», «Kick», «TikTok» і «Чек-лист». Біля кожного сервісу в блоці ключів також є посилання «інструкція», яке відкриває вкладку саме цього сервісу.

Адреси повернення (Redirect URI) в інструкції підставляються автоматично з поточним портом програми й копіюються одним кліком; вони збігаються з тими, які надсилає сервер (`http://localhost:ПОРТ/auth/twitch|youtube|kick/callback`). Вікно закривається клавішею Esc, між вкладками можна ходити стрілками. Кроки звірено з документацією сервісів станом на жовтень 2026; важливі застереження: для YouTube застосунок у Google Cloud треба опублікувати (режим Testing скидає вхід кожні 7 днів), для Kick адреса повернення має містити `localhost`, а не `127.0.0.1`, для Twitch і Kick потрібна двофакторна автентифікація, а для TikTok офіційного входу немає.

## Розділ «🔑 API-ключі» і його перемикач

Перемикач «Використовувати API-ключі для кнопок «Увійти»» (за замовчуванням увімкнено) знаходиться в налаштуваннях «⚙️ Програма», у блоці «API-ключі». Поки галочка стоїть, у налаштуваннях показано окремий розділ «🔑 API-ключі» (одразу під «Підключення»): поля ключів, кнопки «Зберегти ключі» / «Очистити API-ключі» та покрокова інструкція. Коли галочку знято, цей розділ зникає з налаштувань.

Коли перемикач **вимкнено**:
- ховається розділ «🔑 API-ключі» (поля ключів, кнопки збереження й очищення, інструкція) та кнопки «Увійти» біля сервісів, а підказка біля TikTok про відсутність входу зникає разом із кнопкою; «Вийти» перейменовується на «Відключити», щоб канал можна було відключити; сам перемикач у «Програмі» лишається, щоб його можна було ввімкнути знову;
- вимикаються функції: сторінки входу `/auth/...` відповідають відмовою (403), збереження й очищення ключів на сервері відхиляються, не використовуються збережені входи (події Twitch EventSub: фоли, нагороди, Hype Train; API YouTube: пошук трансляції, підписники, глядачі) і необов'язковий ключ Euler Stream для TikTok;
- чат працює далі за ніком чи посиланням на канал (Twitch, Kick, TikTok за ніком, YouTube за @handle, посиланням на канал чи трансляцію);
- збережені ключі й токени входу **не видаляються** (файли `config.json` і `accounts.json` не чіпаються), тож після ввімкнення все працює знову без повторного входу.

Стан зберігається в `settings.json` і діє на всі вікна одразу; платформи, що користуються входом чи ключем (Twitch, YouTube, TikTok), перепідключаються самі.

## «⚙️ Програма» → «🛠️ Для розробників»: Діагностика Kick

У розділі «Програма» є вкладена гілка «Для розробників» (згорнута за замовчуванням). Вона містить службові функції для налагодження. Зараз у ній один пункт, **«Діагностика Kick»**, за замовчуванням **вимкнено**.

Коли її **ввімкнено**: біля Kick у «Підключенні» з'являється кнопка «Діагностика Kick» (така ж кнопка є й у самому розділі), яка відкриває сторінку `/api/kick-debug`: лічильники кадрів, події, які реально приходять від Kick, і журнал підключення. Сервер веде цей журнал (до 120 останніх записів) і друкує записи в консоль. Увага: у журнал можуть потрапити зразки повідомлень чату.

Коли її **вимкнено**: кнопки немає, сторінка діагностики відповідає відмовою (403), журнал не ведеться й нічого не друкується в консоль, а накопичений журнал стирається. Чат Kick працює так само незалежно від перемикача; лічильники кадрів і повідомлень у рядку статусу ведуться завжди. Змінна середовища `DEBUG_EVENTS` для розробників працює окремо від перемикача.

Стан зберігається в `settings.json`, діє на всі вікна одразу, не залежить від перемикача API-ключів.
