# Історія змін MultiChat

Формат версій: [Semantic Versioning](https://semver.org/). Кожен опублікований тег має відповідати `package.json`, а його розділ тут стає описом GitHub Release.

## [1.1.13] - 2026-10-21

### Функції програми
- Об'єднаний чат Twitch, YouTube, TikTok і Kick з підключенням за каналом; OAuth-авторизація Twitch, YouTube та Kick, TikTok через сумісний ключ Euler Stream.
- Українське озвучення чату онлайн- та офлайн-голосами, налаштування голосу/швидкості/висоти/гучності, черга мовлення, фільтри повідомлень, список винятків для глядачів.
- Відображення та озвучення налаштовуваних подій стріму, серед яких підписки, фоли, подарунки, рейди й інші доступні події платформи.
- Лічильники глядачів, індикатори з'єднання, керування чергою й очищенням чату, копіювання повідомлень/ніків/посилань, вимкнення озвучення глядача.
- Окрема панель чату для OBS з керуванням, підказкою з налаштування Browser Dock і відображенням CPU/RAM.
- Налаштування вигляду та продуктивності, апаратне прискорення, режим запуску, пріоритет процесу, діагностика Kick і сповіщення про втрату інтернету.
- Докладний опис усіх функцій і налаштувань — у README.

### Зміни цього релізу
- Додано автоматичне створення Windows-збірки та GitHub Release після push тегу `v<версія>`.
- Додано перевірку відповідності версії тегу, обов'язкових нотаток до релізу та відсутності особистих файлів у пакеті.
- Виключено `config.json`, `accounts.json`, `settings.json`, `.env`, голоси й журнали з репозиторію та EXE-збірки; прибрано копіювання локального `config.json` до папки програми.
- Додано `.gitignore`, документацію приватності та інструкції релізного процесу.
- Збірка Windows використовує іконку MultiChat та Electron 44.9.3 з Node.js 24 для сумісності з актуальною TikTok-бібліотекою.
