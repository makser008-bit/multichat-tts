🔌 Підключення
Акаунти
Підказка про підключення і значки

Twitch, Kick, TikTok: впиши нік каналу. YouTube: вхід через Google. Кнопка «Увійти» - додатковий спосіб авторизації (потрібні ключі, див. нижче; для TikTok вхід недоступний). Далі застосунок сам підключається, щойно ти в ефірі.

Значки угорі: «Онлайн» - стрім у ефірі, «Офлайн» - стріму немає. Крапка знизу показує підключення до чату: зелена - підключено, жовта - підключення, синя - очікування стріму, червона - помилка, сіра - не підключено; червона крапка зверху - LIVE. Клік по значку приховує або показує повідомлення платформи.

🔑 API-ключі
Ключі для кнопок «Увійти»

Створи застосунок на сайті сервісу, встав Client ID і Secret. Redirect URI має збігатися з наведеним. Ключі зберігаються у config.json поруч із програмою.

Ключі приховані; кнопка з оком біля поля показує або ховає лише цей ключ.

    📺 OBS - чат у панелі
    

      

        Параметри панелі
        

          
          

          
          
          
Що саме показувати (лише застосунок чи вся система, обсяг у дужках) налаштовується в блоці «Програма» і діє і в панелі OBS.

          

            Підказка: як додати в OBS
            
OBS → Вигляд (View) → Панелі (Docks) → Користувацькі браузерні панелі (Custom Browser Docks...). Назви панель «Чат», встав посилання вище й натисни «Застосувати». MultiChat має бути запущений.

          

        

      

  

  


  

    ⚙️ Програма
    

      

        Продуктивність
        

  
  

  

  


  
  
  
Для стримінгового застосунку зазвичай достатньо «Звичайний (Normal)» або «Вище звичайного (Above Normal)».

  
⚠️ Увага! Пріоритет «Реального часу (Realtime)» може порушити нормальну роботу Windows, OBS та інших програм і спричинити зависання системи. Не рекомендується використовувати його без особливої потреби.

  


  
  
  

  
Оновлюється раз на 1,5 с, лише поки вікно видно. «Лише застосунок» - частка процесора й пам'яті, яку займає MultiChat (усі його процеси). Прав адміністратора не потрібно.

  
  
  
  
Приклади: «RAM 62% (9,9 ГБ)», «RAM 62% (9,9 ГБ, вільно 6,1 ГБ)» або «RAM 62% (9,9/16 ГБ)». Залишок - вільна оперативна пам'ять усього комп'ютера, весь обсяг - уся пам'ять, встановлена на ПК. У вузькому вікні довші формати скорочуються автоматично.

        

      

      

        Режим запуску
        

  
  

  
ℹ️ Запуск від імені адміністратора надає застосунку розширені права в Windows. Вмикайте цей режим лише тоді, коли він потрібен для роботи певних функцій. Для звичайного використання рекомендується запуск без прав адміністратора.
